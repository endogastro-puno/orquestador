# ============================================================================
# Dependencias PIP del orquestador documental
#
#     python -m pip install -r requirements.txt
#
# IMPORTANTE: los scripts de herramientas/scripts/ NO necesitan nada de esto.
# Funcionan sólo con la biblioteca estándar de Python 3.10+.
#
# Lo de abajo lo necesitan las skills de generación documental:
#   .docx  -> skill `docx`
#   .xlsx  -> skill `xlsx`
#   .pdf   -> skill `pdf`
#
# Esto NO alcanza para generar documentos. Además hacen falta programas que se
# instalan por fuera de pip: Node.js, Pandoc, LibreOffice, Poppler y Tesseract.
# Ver INSTALACION.md y comprobar con:
#
#     python herramientas/scripts/verificar_entorno.py
#
# Sin versiones fijadas a propósito: pip elige la build compatible con tu
# Python. Fijarlas acá rompe instalaciones en versiones nuevas del intérprete.
# ============================================================================


# --- Compartidas ------------------------------------------------------------
# Imágenes: validación visual de páginas renderizadas y ensamblado de PDF.
Pillow


# --- .docx (skill `docx`) ---------------------------------------------------
# Lectura segura de XML de Office, parseo de partes OOXML y validación de campo.
defusedxml
lxml
validators

# Generación de .docx desde Python. La usan los generadores propios del usuario

python-docx


# --- .xlsx (skill `xlsx`) ---------------------------------------------------
# openpyxl: edición por celda. pandas: lectura/escritura masiva.
openpyxl
pandas


# --- .pdf (skill `pdf`) -----------------------------------------------------
# pypdf: estructura y formularios. pdfplumber: texto y tablas.
# reportlab: creación. pdf2image: render de páginas (necesita Poppler).
pypdf
pdfplumber
reportlab
pdf2image
